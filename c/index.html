React Native'de en zor 3 öğe

  1. 01Kart yığını + eğilme + renk/damga geçişi. Gesture Handler Gesture.Pan() → Reanimated useSharedValue; rotasyon, tint opaklığı, damgalar ve arka kartların pozu aynı translateX'ten interpolate. Geri dönüş withSpring, fırlatma withTiming + runOnJS(next).
  2. 02Eşleşme çarpışması + konfeti. Fotoğraflar withSequence(withSpring…); 40 parça konfeti için @shopify/react-native-skia Canvas (tek draw pass, 60fps). useReducedMotion() açıksa yalnızca opaklık geçişi.
  3. 03Sert gölge, grain ve taşan tipografi. Android elevation ofsetli gölge çizmez → gölgeyi ofsetli ikinci View ile kur. Grain: döşenebilir PNG + ImageBackground resizeMode="repeat" (ya da Skia Turbulence). Taşan başlık: overflow:'hidden' kap + maxFontSizeMultiplier.
